# My Course Archive

A personal archive of the courses I've completed during my undergraduate studies.

It contains the study materials I've collected over the semesters, including:

* Lecture slides
* Notes
* Previous questions
* Assignments
* Projects
* Books
* Additional resources

The archive is organized by semester and course, making it easy to browse and find materials for a specific course.

> Some courses may have incomplete collections depending on what materials I have available.

### Built With

* HTML
* CSS
* Vanilla JavaScript

No backend, database, or build tools are required.

### Purpose

This project is mainly a personal academic archive, but it is also intended to make useful course materials easier to browse and revisit.
