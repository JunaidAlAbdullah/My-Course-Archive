# 🚀 QUICK START GUIDE

## Run the Project in 3 Seconds!

### Windows Users:
```cmd
run.bat
```

### Unix/Linux/Mac Users:
```bash
chmod +x run.sh
./run.sh
```

### Manual Method:
```cmd
javac mainx.java
java mainx
```
